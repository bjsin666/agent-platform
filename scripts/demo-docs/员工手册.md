# 员工手册

## 入职与试用期
新员工入职后试用期为三个月。试用期内双方可提前通知解除劳动关系。
转正评估由直属主管负责,评估内容包括工作表现、团队协作与价值观匹配。

## 考勤与休假
公司实行弹性工作制,核心办公时间为上午十点到下午四点。
年假:入职满一年后享有五天带薪年假,每满一年增加一天,上限十五天。
病假需提供医院证明,带薪病假每年不超过十天。
事假需提前一天向直属主管申请,事假为无薪假。

## 薪酬与福利
每月五日发放上月工资,遇节假日顺延。
公司为员工缴纳五险一金,并额外提供补充商业医疗保险。
餐补每月五百元,加班可报销打车费用。

## 行为规范
禁止在工作时间处理与工作无关的私人事务。
对外泄露公司商业机密属于严重违纪,将予以解聘并追究法律责任。
