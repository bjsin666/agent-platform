# 云文档服务协议

## 服务内容
本协议适用于云文档产品及其相关服务。服务提供商为用户提供文档存储、协同编辑与数据同步能力。

## 用户数据
用户上传的文档数据归用户所有。服务提供商仅在提供技术服务所必需的范围内访问用户数据。
用户应自行备份重要数据,服务提供商不承担因用户操作失误导致的数据丢失责任。

## 隐私与安全
服务提供商采用传输加密与存储加密保护用户数据。
除法律要求外,服务提供商不向第三方披露用户数据。

## 服务可用性
服务提供商承诺月度可用性不低于百分之九十九点九。
因维护、升级导致的停机,服务提供商将提前二十四小时通知。

## 协议变更
服务提供商可依法修改本协议,重大变更将提前三十日通过站内信通知用户。
用户继续使用服务即视为接受修订后的协议。
