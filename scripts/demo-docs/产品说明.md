# 云文档产品说明

## 产品定位
云文档是一款面向团队的在线协作文档工具,支持实时编辑、评论与版本历史。

## 核心功能
多人实时协同编辑:多个成员可同时编辑同一文档,改动实时同步。
版本历史:自动保存每次编辑,可随时回滚到任意历史版本。
全文检索:支持对文档内容进行关键词搜索,快速定位信息。
权限管理:支持查看、评论、编辑、所有者四种权限级别,可精确到单篇文档。

## 使用说明
创建文档:在左侧导航栏点击"新建文档",选择空白或模板创建。
共享文档:点击右上角"共享",输入成员邮箱并设置权限。
离线编辑:开启离线模式后,断网期间编辑的内容会在恢复联网后自动同步。

## 价格方案
免费版:单篇文档上限五十兆,协作人数上限十人。
专业版:每月每用户十九元,支持无限存储与高级权限管理。
企业版:按需定制,提供专属部署与技术支持。
